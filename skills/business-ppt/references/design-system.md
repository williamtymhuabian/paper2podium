# 商业 PPT 设计系统（品牌编辑风）

画布 13.33 × 7.5 英寸。边距 M = 0.8"（比学术/竞赛更宽，留白是商业质感的一部分）。
页眉基线 y=0.55，页眉细线 y=1.02，页脚细线 y=6.94。所有坐标单位英寸。

## 1. 三种风格与色板

### 风格 A · 编辑暖白（默认：公司介绍 / 客户提案 / 招商）
```js
const PAPER   = "F7F5F0";  // 暖纸白底（make_backgrounds.py --style editorial）
const INK     = "17191C";  // 墨黑：标题、正文
const MUTED   = "6F6A61";  // 暖灰：注释、来源、页脚
const LINE    = "DAD5C9";  // 细线：页眉页脚、分栏
const ACCENT  = "B4552D";  // 品牌强调（默认赤陶；有品牌色必须替换）
const DARK    = "141715";  // 深色块/引用页底
const ON_DARK = "F4F1EA";  // 深底上的暖白字
```
### 风格 B · 画廊深色（展台大屏 / 产品发布）
```js
const BG      = "0E1110";  // 近黑（make_backgrounds.py --style premium）
const TEXT    = "F4F1EA";  // 暖白主文字
const MUTED   = "A8A399";  // 暖灰次要文字
const ACCENT  = "C96A3F";  // 强调色（比浅色版提亮 8–12%，深底上才跳）
const LINE    = "3A3B36";  // 细线
const CARD    = "1A1D1B";  // 极少数信息块底（非卡片墙）
```
### 风格 C · 品牌单色（强品牌企业）
```js
// brand_kit.py 输出 JSON 后直接引用：
const PRIMARY = "<brand.primary>";  // 品牌主色（标题、强调）
const TINT    = "<brand.tint90>";   // 主色 8–12% 混白：分区底
const PAPER   = "FFFFFF";           // 纯白或品牌极浅 tint
const INK     = "1A1A1A"; const MUTED = "6B6B6B"; const LINE = "E3E3E3";
// 品牌色面积 ≤ 10%；深色版把 PRIMARY 换成同色相更亮一档
```

**共同纪律**：整 deck 一个强调色、一个暖冷调；强调色只用于"想让观众记住的那一个点"
（关键数字、当前节点、CTA），每页至多一处。品牌色再鲜艳也不做整页大色块（展台屏幕除外，
且必须叠影像或降明度）。

## 2. 字体与字号

```js
const F_DISPLAY = "Noto Serif CJK SC";  // 中文标题：宋体族（Windows 无此字时回退 "宋体"）
const F_BODY    = "Noto Sans CJK SC";   // 中文正文：黑体族（Windows 回退 "微软雅黑"）
const F_LATIN   = "Arial";              // 英文标签、数字；大写 + charSpacing 2–4
```
有品牌指定字体时**优先品牌字体**，但必须确认交付机器已安装，否则整 deck 回退会崩版。

| 元素 | 字号 | 说明 |
|---|---|---|
| 封面主标题 | 52–64 | 宋体 Bold，≤ 2 行，行高 1.08 |
| 内页主张标题 | 34–40 | 宋体 Bold，论断句，≤ 18 字 |
| 宣言页大字 | 44–52 | 宋体，2–3 行，行高 1.2 |
| 章节大标题 | 40–44 | 宋体 Bold + 巨号编号 140pt 8% 透明 |
| 英文 kicker | 11–12 | Arial Bold 大写，charSpacing 3，MUTED/ACCENT |
| 正文 | 16–18 | 黑体 Regular，行高 1.5，每段 ≤ 3 行 |
| 图注/来源 | 10–11 | MUTED，必须有出处 |
| 核心数字 | 88–132 | Arial Bold，行高 0.95；单位 24–28 同色降透明 |
| 页脚 | 10 | 左 wordmark，右页码；MUTED |

**远距离字号底线**（1080p 屏）：3m 通道正文 ≥ 24pt、标题 ≥ 48pt；5m 主通道正文 ≥ 28pt、
标题 ≥ 60pt；每行 ≤ 12 个汉字，每页正文 ≤ 3 行。达不到就删字，不缩字号。

## 3. 全局签名元素

### 页眉（内容页，全 deck 统一）
```
x=M, y=0.55: "02 / WHAT WE SOLVE"  11pt Arial Bold 大写，ACCENT 编号 + MUTED 章名
y=1.02: 0.75pt LINE 通栏细线（M → W−M）
y=1.30: 页主张标题 34–40pt 宋体 Bold INK（左对齐，≤ 18 字）
```
封面、全幅图页、章节页不出现页眉。

### 页脚
```
y=6.94: 0.75pt LINE 细线（M → W−M）
y=7.05: 左：品牌 wordmark 10pt Arial Bold 字距 2（MUTED）
        右：页码 10pt Arial（MUTED），"07 / 10"
展台版页脚可加 "展位 B-17 · traveluav.example" 10pt
```

### 编号与细线（本风格的"装饰"）
- 分栏用 0.75pt 竖线（高 3.2–4.5"），不用卡片底
- 数字前的小编号 "01" 用 12pt Arial Bold ACCENT，与标题基线对齐
- 不用项目符号圆点、不用图标、不用阴影、不用圆角卡片（二维码白卡除外）

## 4. 逐页版式配方

### P1 封面（全幅影像，风格 A/B 通用）
- 图片铺满 0–13.33 / 0–7.5，`cover` 预裁到 16:9；上叠 45–55% 墨色矩形（或底部渐变 PNG）
- 左上 x0.8 y0.7：品牌 wordmark 13pt Arial Bold 白，字距 3；其右 0.4" 一条 0.75pt 白线 1.2" 宽
- 主标题 x0.8 y3.05 w8.2 宋体 56pt 白，2 行内；副题 20pt 暖白 80% 透明 y≈4.9
- 底部 y6.3 一条 0.75pt 白 40% 线（x0.8 → 8.3）；线下左：展会名/日期 12pt；右：展位号 12pt
- 二维码（如有）右下 x11.35 y5.75 1.15×1.15" 白卡内缩 0.1"，卡下 10pt 白 "扫码预约演示"
- 封面不放公司简介段落、不放多个 logo

### P2 一句话主张（宣言页）
- 无页眉；kicker x0.8 y0.95
- 主张 x0.8 y2.0 w11.6 宋体 46–52pt INK，行高 1.18，关键词可换 ACCENT（≤ 6 字）
- 下方 y5.55 一条通栏细线；线下三组短语：x0.8 / 4.75 / 8.7，各 w3.5：
  短语 17pt INK Bold + 一行 13pt MUTED 解释
- 右上角可放极简产品剪影/线稿（10% 透明），没有就不放；保持 60% 以上留白

### P3 数字概览（公司介绍必备）
- 页标题 24pt 黑体（不是宋体）："一组数字，说明我们是谁"
- 3–4 个数字横排，y2.55；数字 96–120pt Arial Bold INK，单位 24pt MUTED 同基线
- 数字下 12pt Arial 大写标签 MUTED；再下 13pt 一行解释
- 数字之间 0.75pt 竖线（y2.5–5.2），数字上方一条通栏细线
- 页底 10pt 来源："数据截至 2026-09，经审计" 类真实说明

### P4 问题页（客户提案/展台）
- 标题 = 对方的问题，不是"行业痛点"：如"每一次搜索，仍在消耗三个人和四十分钟"
- 左 45%：3 条问题陈述（编号 + 18pt 一句 + 13pt 一行），行距 0.95"
- 右 55%：一张现场图/示意图全出血到右边缘（x6.0–13.33，y1.2–6.9），不加圆角
- 图下 10pt 来源；没有图时用一条 48pt 的对照数字（如"3 人 / 40 分钟"）占右半版

### P5 产品 hero（展台核心页）
- 全幅产品/场景图铺满；压 30–45% 黑罩（保证白字可读）
- 左下 x0.8 y4.55：一句主张 40–44pt 宋体白（≤ 14 字）
- 主张下 18pt 暖白 80% 一行说明
- 底部三条微标签（x0.8 / 4.2 / 7.6，各 w3.0）：0.75pt 白 40% 线 + 11pt 大写标签 + 14pt 白值
- 不加按钮式色块；CTA 只出现在封面/联系页

### P6 能力三栏
- 页眉 + 标题；三栏 x0.8 / 4.75 / 8.7，各 w3.55，栏间 0.75pt 竖线 y2.25–6.1
- 每栏：编号 12pt ACCENT → 标题 24pt 宋体 Bold（y2.35）→ 正文 15pt（y2.95，≤ 3 行）→
  一条 0.75pt 短线 + 12pt MUTED 证据/参数（y5.7）
- 三栏必须同一结构、同一字数级；不放大其中一栏（想突出就单独开页）

### P7 证据页（数据/评测）
- 标题 = 结论句："零样本场景下，成功率仍为基线 2.1 倍"
- 左 58%：图表区 x0.8 y1.9 w7.4 h4.4；柱/线用 INK + 一个 ACCENT 高亮，其余灰阶 `B9B3A8`
- 右 34%：2–3 条解读（16pt，每条 ≤ 2 行），关键数字 30pt Arial Bold ACCENT
- 图下 10pt 来源；右下角 10pt "n=…，评测集…" 方法注
- 不用 3D、不用渐变填充、不用图例框；直接标注系列名

### P8 案例页（影像 + 悬浮信息板）
- 左 57% 全出血现场图（x0–7.6，y0–7.5），压 20% 黑罩；图上左下 12pt 白 "CASE 01 / 城市应急"
- 右 43% 暖白信息板（x7.6–13.33，y0–7.5），内边距 0.9"
- 板内：客户类型 13pt MUTED → 一句结果 30pt 宋体 Bold（≤ 2 行）→ 三条指标（数字 40pt + 标签 12pt，
  纵向排列，细线分隔）→ 底部一句客户原话 15pt 斜体 + 署名 11pt（**必须有授权**）
- 没有真实案例时改放"试点场景"并明确标注"试点"，不写客户名

### P9 引用/愿景页（深色，节奏页）
- 深色底（风格 A 用 DARK，风格 B 用 BG）；无页眉
- 右上或左下巨大引号 "“" 160pt ACCENT 8% 透明
- 引文 x0.8 y2.3 w11.5 宋体 34–38pt ON_DARK，行高 1.35；署名 14pt MUTED y5.9
- 一句即可，超过 3 行就删；这是全 deck 唯一允许"只有一句话"的页

### P10 合作/信任状
- 标题 24pt："与谁同行" 或 "资质与认可"
- logo 墙：灰度、等高（视觉高度 0.45–0.6"）、4 列 × 2 行，单元 2.9×1.2"，居中对齐；
  logo 之间无框无底线；没有授权 logo 就换成资质/专利/媒体报道的文字条目（12pt + 细线）
- 底部一行 13pt MUTED 说明合作性质（"联合试点 / 供应商 / 投资方"），避免误导

### P11 路线图
- 页眉 + 标题；主轴线 y4.35，x0.8–12.5，1pt LINE
- 4 个节点（0.18" 圆点）：已完成 INK 实心、当前 ACCENT 实心 + 外环、未来空心
- 节点上：年份 28pt 宋体（y3.35）；节点下：里程碑 15pt Bold（y4.65）+ 一行 13pt MUTED（y5.0）
- 节点间距均等；最多 5 个；不画箭头、不画彩色进度条

### P12 联系/CTA（展台收尾页）
- 深色或品牌浅 tint 底；无页眉
- 左 60%：kicker "NEXT STEP" → 标题 44pt 宋体"把您的场景交给它" → 三步行动（01 扫码预约 /
  02 30 分钟场景评估 / 03 两周试点），每步 18pt + 13pt 说明，细线分隔
- 右 35%：二维码白卡 2.0×2.0"（内缩 0.14"），卡下 12pt 动作指令；再下联系方式 13pt（邮箱/电话/官网）
- 左下：展位号 72pt Arial Bold ACCENT + "BOOTH" 11pt 标签（展台版）
- 循环版此页停留 10 秒，之后直接回封面；不放"谢谢观看"

### 章节过渡页（仅公司介绍/提案版）
- section 背景；巨号编号 "02" 140pt 宋体 ACCENT 8% 透明置右下；
- 章名 40pt 宋体 Bold INK y3.0；一行 18pt MUTED 概括本章回答的问题；页脚不显示页码

## 5. 影像规则

- 全幅图先按 16:9 预裁（PIL），再铺满；不要用 pptx 拉伸
- 统一色调：同一 deck 的现场图做同一组「暖 + 降饱和 10% + 提对比 5%」处理，避免一张冷一张暖
- 人物图必须获得肖像授权；展台图避免可识别的路人正脸
- 产品图：统一背景、统一投影方向；抠图边缘 1px 毛边宁可裁成方图放色块，不要硬抠
- 深色页上的截图/白底图：0.75pt `3A3B36` 描边；浅色页上深色截图：0.75pt `DAD5C9` 描边
- 图标只在流程图必要处使用线性图标，统一 1.5pt 线宽、INK/MUTED 两色；不做图标墙

## 6. 动效与展台播放

- 公司介绍/提案：不加动画（PPT 是阅读材料，动画只会暴露不专业）
- 展台循环：仅用 0.4s 淡入淡出；`set_loop.py` 写入自动换页与循环放映
- 循环节奏：封面 8s → 主张 8s → 问题 8s → 产品 10s → 能力 10s → 证据 10s → 场景 10s →
  交付 8s → 联系 12s；总 84s，落在 60–90s 的展台注意窗口内
- 屏幕常亮场景避免大面积纯白（亮度刺眼、OLED 烧屏）；同一静态元素不要连续停留 > 2 分钟，
  循环本身即可缓解；展台机开启屏保/定时重启策略由现场 IT 负责
