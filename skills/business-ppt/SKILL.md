# 商业 PPT（企业展出 / 公司介绍 / 商务提案）

为企业**对外**场合产出有品牌质感、远距离可读、不依赖讲解也能看懂的演示文稿。
三个核心判断：**这是给谁看的、在多远处看、看完要做什么**。展会大屏前观众只停留 3–7 秒，
客户提案桌上对方只关心"你懂不懂我的问题"，公司介绍只需要回答"你是谁、凭什么信你"。

构建工具链与另外两套 skill 一致（python-pptx / pptxgenjs 均可，画布 13.33 × 7.5"），
本 skill 负责商业场景的设计系统、叙事结构、品牌素材管线与展台交付。写构建脚本前按需读：

- `references/design-system.md` —— 三种风格色板 / 字体 / 逐页版式配方（含坐标），**必读**
- `references/narrative-and-pages.md` —— 四种 deck 模式、页数配比、每页内容清单，**必读**
- `references/asset-pipeline.md` —— 品牌取色、产品图处理、二维码、展台循环导出，**有品牌物料/展台交付时必读**

## 0. 触发后第一件事：锁定商业参数

按顺序确认，缺一项就问，不要靠猜：

1. **场景模式**（决定页数与节奏）
   - 展台循环（无人讲解，屏幕轮播）→ 8–10 页，每页 6–10 秒，总循环 60–90 秒
   - 公司介绍（拜访/招商/官网下载）→ 12–16 页，可独立阅读
   - 客户提案（面对已知客户）→ 14–20 页，以"我们理解你的问题"开场
   - 产品发布（发布会/媒体）→ 10–14 页，一个大主张 + 一个 hero 产品
2. **品牌资产**：logo（矢量优先）、品牌主色、指定字体、产品图/场景图、公司全称与英文名、
   官网/二维码目标链接、展位号。没有 logo 就用文字 wordmark，**绝不画一个假 logo**
3. **观看条件**：屏幕尺寸与分辨率（展台常见 1080p/4K 竖屏或横屏）、最近观看距离（1.5m 洽谈 /
   3m 通道 / 5m 主通道）、是否静音、是否循环
4. **商业事实**：客户数、营收、市占率、案例、资质、融资——**只写有出处的数字**；
   没有就换成定性表述，不编市场数据、不编客户 logo、不编评价

## 1. 选风格（先定调，再排版）

| 风格 | 适用 | 一句话 |
|---|---|---|
| **A 编辑暖白（默认）** | 公司介绍、客户提案、招商 | 暖纸白 + 墨黑 + 单一品牌色，宋体大标题、细线、大留白，像一本品牌年鉴 |
| **B 画廊深色** | 展台大屏、产品发布、晚间活动 | 近黑底 + 暖白字 + 全幅影像 + 一处强调色，屏幕边界消失，3 米外冲击力最强 |
| **C 品牌单色** | 医药、工业、金融等强品牌企业 | 以品牌色 tint 为底/点缀，其余同 A；品牌色由 `brand_kit.py` 从 logo 提取 |

同一套 deck 只用一种风格；深色封面 + 浅色内页的"三明治"只在公司介绍版允许。
**禁止**把竞赛版的深空科技蓝、卡片格子、超大金色数字搬过来——那是学生竞赛语汇，不是企业语汇。

## 2. 生成背景（本风格的根基）

```bash
python3 <skill_dir>/scripts/make_backgrounds.py -o bg/ --style editorial   # 暖纸白（默认）
python3 <skill_dir>/scripts/make_backgrounds.py -o bg/ --style premium     # 画廊深色
python3 <skill_dir>/scripts/make_backgrounds.py -o bg/ --style brand --brand 1F4E79  # 品牌色 tint
```

产出 `cover/section/content` 三张 2560×1440 PNG。内容页必须用 `content` 版（更安静）；
展台循环建议用 `premium` 的 content 背景，避免大面积纯白在展馆强光下刺眼、也避免烧屏。

## 3. 品牌素材管线

```bash
# 从 logo 提取品牌色板 + 生成单色 logo（深底/浅底各一版）
python3 <skill_dir>/scripts/brand_kit.py logo.png -o brand/

# 展台交付：给 deck 写入自动换页 + 循环放映（PowerPoint 打开即无人值守轮播）
python3 <skill_dir>/scripts/set_loop.py deck.pptx --seconds 8 --fade
```

- 品牌色只取 1 个主色 + 1 个强调色；提取结果要人眼复核，灰调/渐变 logo 可能给出脏色
- 产品图统一处理：同一背景（品牌浅灰/暖白/近黑）、同一光线方向、同一投影；抠图不干净就裁成
  统一比例放在色块上，不要硬抠
- 二维码只放一个，指向**具体落地页**（预约演示/领取白皮书/加企微），不指向官网首页；
  展台二维码最小 1.2"，放在右下角或联系页，旁边一行 14–16pt 动作指令
- 细节见 `references/asset-pipeline.md`

## 4. 设计系统（摘要，细节见 references/design-system.md）

- **A 编辑暖白**：底 `F7F5F0`；墨 `17191C`；次要 `6F6A61`；细线 `DAD5C9`；
  强调色 = 品牌主色（无品牌时用赤陶 `B4552D`）；深色块 `141715`
- **B 画廊深色**：底 `0E1110`；字 `F4F1EA`；次要 `A8A399`；强调色同上；影像压 45–60% 黑罩
- **字体**：中文标题宋体族（思源宋体/Noto Serif CJK SC，Windows 可回退宋体）Bold 36–56pt；
  正文思源黑体/微软雅黑 16–20pt；英文标签 Arial 大写 + 字距 2–4pt，11–13pt；数字 Arial
- **签名元素**：左上角 `01 / WHO WE ARE` 式章节编号 + 大写英文 kicker；页脚左品牌 wordmark、
  右页码；贯穿全 deck 的 1px 细线；**没有卡片、没有阴影、没有图标堆叠**
- **一个焦点**：每页只有一个超大元素（一张全幅图 / 一个 100pt+ 数字 / 一句 40pt+ 主张），
  其余信息降到注释级
- **数据**：一页一个结论句 + 一个数字 + 一行来源；图表只用一个强调色，其余灰阶

## 5. 商业叙事（摘要，细节见 references/narrative-and-pages.md）

- **展台循环**：品牌与品类 3 秒内说清 → 一句主张 → 问题 → 产品 hero → 三项能力 → 证据 →
  场景 → 交付方式 → 信任状 → 扫码。**没有目录页、没有谢谢页**（循环里"谢谢观看"是死帧）
- **公司介绍**：我们是谁（一句话+数字）→ 解决什么问题 → 产品/服务 → 能力 → 案例 → 伙伴/资质 →
  团队 → 联系
- **客户提案**：执行摘要（先给结论）→ 我们对你问题的理解 → 代价 → 目标与成功指标 → 方案 →
  实施计划 → 案例证据 → 投入产出 → 风险与保障 → 下一步
- 标题写**商业主张**，不写栏目名：❌"我们的优势" ✅"同样人手，巡检覆盖提升 3 倍"
- 每页回答：谁在 3 秒内记住什么？证据是什么？看完做什么？

## 6. 构建要点

- `LAYOUT_WIDE` 13.33×7.5；色板常量置顶；全 deck 显式指定字体
- 版式配方（含坐标）在 `references/design-system.md`，按页型取用，不要每页自创
- 图像：全幅用 `cover` 裁切并预裁到目标比例（先算比例，禁止拉伸）；产品图用等比完整展示；
  深色页上的白底图加 0.75pt 浅色描边
- 细线用 0.75–1pt 实线，不用阴影模拟；圆角仅用于二维码卡片等小元素
- 数字用原生文本框（Arial Bold），图表用原生 `addChart` + 单色高亮；
  时间轴/流程图用原生细线 + 圆点，不用彩色 chevron
- 动画默认不加；展台循环需要转场时统一 0.3–0.5s 淡入，不做位移/旋转

## 7. QA（交付前）

1. **远距离可读性**：把每页渲染成 1920px PNG，再缩到 480px 模拟 3–5m 观看——
   还能读出主标题和核心数字才算过；正文在 1080p 下 ≥ 24pt（3m）/ ≥ 28pt（5m）
2. **静音测试**：关掉声音、不看备注，能否在 3 秒内判断"这家公司做什么、对我有什么用"
3. **溢出检查**：python-pptx 脚本查文本越界/形状出画布；渲染 PDF → PNG 逐页目检
4. **品牌一致性**：logo 四周留白 ≥ logo 高度的 1/2；品牌色不与其他高饱和色同页；
   字体不超过两种中文 + 一种英文数字
5. **事实检查**：每个数字有来源（脚注 10–11pt）；客户 logo/评价已获授权；无占位符（xxx/TODO/lorem）
6. **展台交付**：`set_loop.py` 写入循环；在实际屏幕比例下试播一轮；二维码用手机实扫
7. 交付命名：`<公司>_公司介绍_2026.pptx` / `<公司>_<展会>_展台循环.pptx`；
   同时给 PDF 预览与 `讲稿_展台循环.md`（每页字幕 + 30 秒口播 + 3 分钟讲解版）

## 8. 商业场合禁忌

- ❌ 编造客户 logo、用户评价、市占率、融资额（法务与信誉风险，远大于画面收益）
- ❌ 把内部数据/未发布产品放进对外版本；对外 deck 默认按"会被拍照转发"来审
- ❌ 满屏小字、五颜六色、3D 图表、阴影卡片、图标墙——企业审美减分项
- ❌ 展台页放长段落（观众不读）；一页超过 3 行正文就该拆页或降级为口播
- ❌ 纯白全屏长时间静态展示（展馆强光下刺眼、OLED 烧屏）；用暖白或深色并让元素缓慢变化
- ❌ 二维码指向官网首页、放得太小、没有动作指令
