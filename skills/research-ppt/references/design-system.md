# 科研 PPT 设计系统（Nature/Science 学术美学）

画布 13.33 × 7.5 英寸，边距 M = 0.6"，正文块间距 0.35"。
原则：白底、克制、图为证。所有坐标单位英寸。

## 1. 配色

### 默认色板（学术蓝灰）
```js
const BG      = "FFFFFF";  // 内容页背景（纯白）
const BG_SOFT = "F6F8FA";  // 分区底/表头浅底（可选）
const PRIMARY = "1F4E79";  // 深学术蓝：标题、图框强调、表头文字
const ACCENT  = "C0392B";  // 学术红：仅用于最优值加粗、gap 框、单个关键词
const TEXT    = "2B2B2B";  // 正文
const MUTED   = "6B7280";  // 图注、来源、次要信息
const LINE    = "D8DEE6";  // 分隔线、三线表线
```

### 学科变体（只换 PRIMARY/ACCENT，其余不动）
- 计算机/工程/医学：蓝 `1F4E79` + 红 `C0392B`（默认）
- 生命科学/环境/农林：墨绿 `1E5E4E` + 橙 `D55E00`
- 数学/物理/理论：石墨蓝灰 `37424E` + 蓝 `0072B2`
- 人文/社科/历史：绛紫 `5B3A5E` + 金 `B8860B`
- 学校有主题色时优先吸收为 PRIMARY

### 数据系列色（Okabe-Ito 色盲安全板，按序取用）
```
0072B2(蓝) E69F00(橙) 009E73(蓝绿) CC79A7(红紫) 56B4E9(天蓝) D55E00(朱红) 000000(黑)
```
单系列图只用 PRIMARY；对比图用 [PRIMARY, ACCENT]；≥3 系列才引入 Okabe-Ito 全板。

### 深色封面（可选三明治）
封面/章节页/致谢页可用深蓝 `1F4E79` 底 + 白字 + 浅蓝 `9DC3E6` 次要文字；
内容页一律白底。不确定时全白也完全成立（答辩最稳）。

## 2. 字体与字号

```js
const FONT = "微软雅黑";   // 全 deck 显式指定；苹果机器自动回落 PingFang，可接受
// 封面主标题可有衬线变体：标题字体 "思源宋体"/"宋体"（仅标题，且需答辩机已装；拿不准就不用）
```

| 元素 | 字号 | 字重 |
|---|---|---|
| 封面主标题 | 40–44 | Bold |
| 封面副题/信息 | 18–20 | Regular |
| 页标题（论断句） | 26–30 | Bold，PRIMARY |
| 正文要点 | 20–24 | Regular，每页 ≤6 行 ≤30 词 |
| 图表轴标签/图例 | 14–16 | — |
| 图注/来源行 | 12–14 | MUTED |

标题行高 1.15；要点 `paraSpaceAfter: 8`；中文短句不加句号。

## 3. 逐页版式配方

### A. 封面
- 白底版：校徽图 0.9×0.9" 置 (M, M)；主标题 44pt Bold PRIMARY 居中 y≈2.5；
  副题（论文题目/英文题）18pt MUTED；底部信息行（汇报人/导师/单位/日期）16pt TEXT 居中 y≈6.3
- 深蓝版：PRIMARY 全幅底，同结构白字；徽标放白色圆形托底上（透明底徽标直接放）
- 无校徽时不得画装饰图形代替，留白即可

### B. 汇报提纲（可省略）
左侧 "目录/CONTENTS" 24pt Bold，右列 4–6 条编号条目 20pt，行距 0.62"；
编号用 PRIMARY 数字 24pt Bold + 正文 TEXT。不加框不加图标。

### C. 背景页（漏斗式，2–3 页由宏观到具体）
- 宏观页：左 55% 文字（3 条要点），右 45% 一张领域图/趋势图（native addChart 折线最佳）
- 具体页：上图下文或左图右文，图占 55%；来源行 12pt MUTED 置页底 M 处
- gap 强调：一句话用 ACCENT 色 Bold，或 1pt ACCENT 描边框（无填充）围住 research gap 表述

### D. 相关工作对比表
三线表：表头行 PRIMARY 底白字（或 BG_SOFT 底 PRIMARY 字）20pt Bold；
数据行 18–20pt；三线 = 顶部 1.5pt PRIMARY 线 + 表头下 0.75pt 线 + 底部 1.5pt 线，中间无竖线；
本文方法行可用 BG_SOFT 底突出，优于对手的单元格 ACCENT 加粗。

### E. 方法总框架页（本 skill 的招牌页）
- 页标题 = 论断句（"XX 框架：以 Y 实现 Z"）
- 框架图（extract_figures 提取）全宽放置：宽 = 12.13"（W−2M），高按宽高比算，
  垂直居中于 y 1.6–7.0 区间；图下 12pt 图注："图源：本文 Fig.2 | 编码器将…（口语化重写）"
- 框架图超过 ~5.2" 高时宽改 10.5" 居中，两侧留白优于压扁
- 需要逐模块讲解时：本页之后再开"模块页"——右 60% 放框架图局部（--crop 从原图裁），
  左 40% 放 2–3 条要点，要点编号 ①②③ 与图中模块颜色呼应

### F. 实验结果页（assertion–evidence 标准页）
- 页标题 28pt 论断句
- 主图区：单图居左 7.2" 宽（高按比例，垂直居中），右侧 4.3" 放 2–3 条要点；
  要点为短语，重要数字 ACCENT Bold 且放大到 28–32pt
- 多子图 (a)(b)(c)：等间距并排，各图下方 14pt 子图标签；面板间距 0.3" 统一
- 结果表：同 D 配方；最优值加粗 + ACCENT

### G. 结论页
"结论与贡献" 标题 + 3–4 条编号贡献（20–24pt，每条 ≤2 行，编号 PRIMARY Bold）；
下方一行 MUTED 14pt "不足与展望：…"（体现学术诚实，答辩加分）。

### H. 致谢/Q&A
"谢谢各位专家 敬请批评指正" 36pt PRIMARY 居中；下方 16pt 汇报人/联系信息；
可附 "备查页" 目录提示。深蓝底白字亦可。

### I. 附录/备查页
标题 24pt "附录 A：…" + 完整表格/推导/额外实验；页码继续编或用 "A1"。

## 4. 图像处理规则

- 所有位图先 `python3 -c "from PIL import Image; ..."` 读真实像素或直接用 manifest 的 w_px/h_px，
  按目标盒子计算等比尺寸再给 x/y/w/h —— **禁止**同时手写 w 和 h 造成变形
- 需要裁剪显示用 `sizing:{type:'cover'}`；学术图优先完整展示用 contain 思路（自己算尺寸）
- 450dpi 提取的图放全宽不糊；若 manifest 显示原图 < 800px 宽，全宽放置前提醒用户找原图
- 深蓝背景页上放白底论文图：给图加 0.75pt `LINE` 描边（`line:{color:"D8DEE6",width:0.75}`）避免"白块浮起"

## 5. 图注写法（学术惯例）

格式：`图 N｜结论句。细节说明。`（"｜"后第一句是该图的 takeaway，不是内容罗列）
- 误差/统计必须写全："误差线 ±s.d.，n=5，**p<0.01"
- 复用论文图必须重写图注为口语化版本，并标注 "图源：作者 et al., 年份, Fig.N"
- 图注置于图正下方，左对齐图左缘，12–14pt MUTED，最多两行
