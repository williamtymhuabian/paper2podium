# 竞赛叙事线与页面清单

## 1. 两种版本

| 版本 | 场合 | 页数 | 特征 |
|---|---|---|---|
| 路演版（默认） | 现场答辩 8–10 min | 20–28 | 每页一个焦点、大数字、图多字少、讲稿进备注 |
| 网评版 | 评委离线审阅 | 30–40 | 信息更全、每页可独立阅读、补充细节页与附录 |

时长换算：约 1 页/25 秒；8 分钟 ≈ 20–24 页，10 分钟 ≈ 26–28 页，超页必被评委叫停。

## 2. 路演版标准章节（6 章 22 页基线，按项目裁剪）

| 章 | 页数 | 页面 |
|---|---|---|
| 01 项目背景 | 3 | 封面 → 目录 → 行业痛点（数据冲击页） |
| 02 解决方案 | 4 | 章节页 → 产品/方案总览 → 创新点（3 条）→ 应用场景/案例 |
| 03 核心技术 | 5 | 章节页 → 技术架构图（论文框架图）→ 关键技术 1 → 关键技术 2 → 知识产权/成果证明 |
| 04 市场与模式 | 4 | 章节页 → 市场规模（TAM/SAM/SOM）→ 竞品对比（矩阵）→ 商业模式 |
| 05 团队与基础 | 3 | 团队介绍 → 指导教师/依托平台 → 已获荣誉/融资进展 |
| 06 规划愿景 | 3 | 里程碑路线图 → 社会价值/愿景 → 致谢 |

学术类（大挑）调整：02 章换成"研究背景与科学问题"、03 章扩为"研究内容与方法（5–7 页）+
实验结果（2–3 页，数据成果页在此）"、04 章换"应用前景"。创业类（小挑/大创主赛道）用上表原样。

## 3. 每页内容自检（写脚本前逐页填表）

每页回答四问，缺一就重想该页：
1. **一句话主张**（这页让评委记住什么？≤15 字）
2. **证据**（数字/图/实物照/证书——必须有，且标注来源）
3. **焦点元素**（超大数字 / 大图 / 图表，唯一）
4. **口播讲稿**（30 秒内说完，写进 speaker notes）

## 4. 评委高频提问 → 对应备查页（附录）

- 技术壁垒在哪、与顶会方法差距 → 附录：技术对比表、消融实验
- 数据是否真实 → 附录：测试集说明、第三方检测报告图
- 市场数字出处 → 附录：测算逻辑（自上而下 + 自下而上）
- 成本与定价 → 附录：BOM/成本结构表
- 团队持续性 → 附录：分工与股权/学分制安排

## 5. 命名与交付

- 文件名：`<项目名>_<赛事><阶段>路演.pptx`，如 `慧检_挑战杯国赛路演.pptx`
- 同时交付：figures/（提取图）、bg/（背景）与构建脚本，便于下一轮迭代改字重跑
- 网评版可另存 PDF 一并交付（`soffice --convert-to pdf` 顺手完成）
